---
title: Administering the platform
description: "For platform admins and auditors of Open MCP Portal: people and teams, the catalog, access, records and operations."
---

Platform admins run an Open MCP Portal installation from the **Admin** side of the web app (the **Workspace / Admin** switch at the top of the sidebar). Platform auditors see every admin page, read-only.

Platform roles don't reach into teams' content: a platform admin uses a team's gateways only as a member of the team, uses a platform gateway only when granted, never changes a team's servers through the team's pages, and reads recorded call contents only through Admin › Calls, where every view is audited.

The admin sidebar groups these pages as **People** (Users, Teams, Provisioning), **Catalog** (MCP servers, Publishing, Internal networks), **Access** (Approval rules, Gateways, Trusted clients, Auth providers, Automation tokens), **Records** (Audit log, Calls, Usage) and **Operations** (Limits, Retention, Payload capture, Notifications).

Settings that must exist before the database is read (addresses, sign-in, keys) are environment variables; see [Configuration](/docs/operate/configuration).
